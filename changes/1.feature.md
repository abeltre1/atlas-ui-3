The bundled `filesystem` MCP server now mounts one chosen local directory into the chat and is built for the agent loop: `ATLAS_FS_ROOT` picks the directory (the server refuses to start if it is missing), `ATLAS_FS_READ_ONLY=true` hides the write, edit, create and delete tools from the model, `read_file` returns large files in pages, and new `search_files`, `search_content` and `edit_file` tools let the model find and change files without loading them whole. Every tool stays confined to that directory, including through symlinks. The admin panel now shows why a server with an unresolved `env` variable failed to start, and the hook examples use the real `<server>_<tool>` matcher spelling.
