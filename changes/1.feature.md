The bundled `filesystem` MCP server now mounts one chosen local directory into the chat: `ATLAS_FS_ROOT` picks the directory (the server refuses to start if it is missing), `ATLAS_FS_READ_ONLY=true` hides the write, create and delete tools from the model, `ATLAS_FS_MAX_READ_BYTES` caps how much `read_file` returns, and a new `get_mount_info` tool reports what is mounted. Every tool stays confined to that directory, including through symlinks.
